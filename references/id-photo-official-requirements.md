# 按用途核对证件照要求

规则核验日期：2026-10-22。索引见 `../assets/id-photo-purpose-profiles.json`。这些是有来源和适用范围的规则，不是永久有效的全球通用标准；正式制作前核对接收机构当前页面。记录用途、地区／接收机构、办理渠道、来源链接、核验日期和适用限制。页面失效或规定冲突时不能记为已核实。

## 先确定用途

| 路由 | 必须明确的上下文 | 不能借用的规则 |
|---|---|---|
| 中国居民身份证 | 受理地区／机关、现场采集或照片回执等渠道 | 普通一寸／二寸；其他地区现场受理政策 |
| 中国护照／旅行证纸质照 | 受理机关／使领馆、纸质提交 | 300 DPI 换算像素直接当网办规格 |
| 中国出入境网办上传 | 证件类别、具体平台和受理渠道 | 纸质规格直接覆盖电子文件要求 |
| 考试／报名照 | 考试名称、年度／场次、地区、报名入口 | 一个考试的眼镜、底色或体积限制套给所有考试 |
| 外国签证／护照 | 国家／地区、证件种类、使领馆或上传入口 | 默认沿用中国身份证的耳饰或露耳规定 |
| 普通尺寸／造型样张 | 用户选定尺寸与审美即可 | 只能称尺寸样张／造型预览，不判定官方用途合格 |

只说“一寸白底”不会自动得到身份证资格；已知用途时先查用途规则，再确定尺寸。仅做普通样张无需强行追问官方用途，但必须标清样张。已知官方用途而关键渠道缺失时，一次问齐；推荐方案只能推荐待核实的用途分流，不能把未知要求填成已通过。

## 中国居民身份证

北京市公安局发布的[拍照须知](https://www.bjfsh.gov.cn/ztzx/2023/zzxbs/hzda/jmsfz/cjwd/202312/t20231205_40069285.shtml)规定：深色衣服且领子不能为浅色，不着制式服装；不戴项链、耳环；头发整齐、刘海不遮眉，女士绑发露耳；不浓妆，并有该地眼镜／隐形眼镜要求。该来源只支持相应地区指引，不能声称是全部用途统一规定。

[北京官方尺寸说明](https://www.beijing.gov.cn/fuwu/bmfw/bmzt/sfz/rdgz/201809/t20180917_1857547.html)列出相片26×32 mm、两耳根间脸宽15±1 mm；这不等于将普通一寸裁成26×32 mm后就可以上传，电子采集参数以实际受理渠道为准。[姚安公安2026年指引](https://yaoan.gov.cn/info/2873/499464.htm)要求当地现场拍照，不能自带照片，同时要求深色衣服、不遮眉耳、不戴耳环项链。不把该地现场采集政策推广为全国一律不能交回执照。

默认保守造型可采用深色、有袖、领口端正的素色上衣、无首饰、头发整理到耳后／扎起。**有袖和端正领口是工坊推荐，不冒充上述来源逐字规定。**耳朵应自然显露，不通过拉大耳朵、挪动耳位等改变生理结构。

## 中国护照／旅行证纸质照

[中国驻汤加使馆2025-06-12指引](https://to.china-embassy.gov.cn/chn/lsfw/zjbl/lsqw_133413/202506/t20250612_11646385.htm)要求近6个月、白底、面部和背景无阴影，完整头面部、自然表情；头发不得挡眉、眼、耳；有色镜片及遮眼／反光不可接受。宗教头部覆盖物有不遮面条件，不擅自套用“任何情况都不能戴头巾”。该页允许符合条件的眼镜及助听设备，不能误写为全部禁戴。

纸质参考为33×48 mm，头宽15–22 mm、头高28–33 mm、头顶距上边3–5 mm、下巴以下至少7 mm。数值按此用途独立检查，不用通用构图范围判定；照片实际测量与打印尺寸、接收馆规则一起核对。

该来源明确禁止修改及合成照片。真实办理不能用AI新造头像、虚构耳朵、合成换装或数字去耳饰来绕过采集要求；需要本人整理头发、摘饰并按渠道重新拍摄。即使非生成式调整，也须先确认渠道允许，不能默认背景替换或轻度精修一定可用。

该页没有给出“所有首饰一律禁止”或“必须穿有袖深色上衣”的统一条款。无饰、深色端正上衣可以作为工坊保守建议；若实际受理机构明确禁止首饰，则升级为该渠道硬性检查项。不能把建议写成该页官方原文。

## 网办、考试与外国证件

- 出入境网办：先读[国家移民管理局指引入口](https://www.nia.gov.cn/n741445/n741619/n894511/c896346/content.html)，再核对实际上传入口的像素、文件体积、底色、裁切、编辑限制和采集／回执方式。只有总入口不能证明已核实某平台当前规则。
- 考试：以当前考试公告为准。例如[剑桥少儿英语照片FAQ](https://cyle.neea.cn/xhtml1/report/18051/6315-1.htm)要求露眉耳、不戴眼镜，建议白底；[DELE照片FAQ](https://dele.neea.cn/xhtml1/report/19041/7938-1.htm)列白或蓝底、二寸与文件格式体积。这两份旧FAQ仅说明规则确有差异，制作当届照片仍需核对当届入口，不默认沿用旧体积限制。
- 外国签证／护照：到目的地政府或使领馆查询耳朵、首饰、眼镜、表情、尺寸、采集与修图规定；未核实就不标合格，不套中国身份证模板。

## 必须逐项验收

除保真、清晰度、姿态、背景、自然比例外，再查：眉眼与耳廓是否按用途露出；耳饰、项链和头饰；衣服、领口及制服限制；妆容、眼镜和美瞳；表情；用途专属头部尺寸；是否允许当前处理；渠道是否接受该采集方式。每项写具体观察及规则依据。来源没有禁止的项目记录为“已查该来源无此硬性禁令，采用工坊建议／检查遮挡”，不能捏造禁令，也不能省略检查。

文件参数通过、造型视觉通过、该用途本地核对通过、机构接收是不同结论。任何必填要求待定都不能标正式交付就绪。检查器只核对记录完整性与文件绑定，不自动识别耳环、验证身份或判断网页规则是否真的适用。

## 合成测试与真实办理分开

用户明确授权用虚构人物测试时，可以依据已确认参考生成扎发、无饰、深色着装的造型对比；直接生成一张完整预览，在图外醒目标“AI测试样张／非办证提交照片”。按所示用途检查可见造型和取景，但不能声称符合真实采集、近期本人、禁止合成等全部官方要求。预览不等于独立像素文件或毫米打印验收，用户要求独立样张后再按用途精确导出。

此测试不证明真实客户保真，不把测试生成变成官方客户制作路径，也不自动替换已确认人物参考。检查器的 `--test-sample` 可以评估已记录的测试检查，但必须保持 `delivery_ready: false`；真实官方交付不允许此开关代替用途核验。
