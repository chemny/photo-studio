# 创意人像摄影导演规则

适用于婚纱照、全家福、亲子照、个人形象照和艺术写真的候选画面与正式成片。证件照以官方规格、构图和身份保真为先，不套用创意导演规则。各产品的专用规范仍决定人物、服装、画幅、格数和审美边界。

## 先设计画面，再写生成要求

每张照片或每个候选画格在内部确定以下内容，不把这张检查卡当成表单展示给用户：

1. **用途与不变量**：这张照片要让人看到什么？锁定用户明确指定的入镜人物、场景、服装、色彩、动作、比例，以及已确认的身份特征。默认预设只能补空白，不能覆盖明确要求。
2. **拍摄瞬间**：选择一个可拍摄的时间切片，以及一个轻微事件或明确的稳定姿态目的。正式主合影可以是安稳看镜头，不必强加剧情；互动照应能说清人物正在共同做什么。
3. **动作链与视线**：交代身体重心、站坐关系、手部动作、人物接触点、头部方向和视线落点。多人画面还需说明谁在前、谁在后，以及是否存在自然的高低差。每个动作都要适合人物年龄、服装和场地。
4. **空间与摄影**：只选两三个能辨认环境的线索，确定景别、机位、前后层次、构图目的和光源方向。人物、衣物、道具和背景应处在同一可信光线中。
5. **一致性检查**：人物行为、服装、天气或时间、空间和光线必须能同时出现在这一瞬间。提示词要描述完整画面，不能只并列“高级、自然、电影感、漂亮背景”等词。

## 多格预览与单张成片

- 多格预览先按产品规范确定格数和比例，再为每格安排不同的拍摄目的或人物关系；场景、动作、景别和情绪应形成可见差异。更换背景或服装本身不算新的摄影瞬间。
- 宽泛的人像多格预览还要安排不同的人物尺度与空间关系：头像近景用于识别人物，环境半身与全身照用于呈现可进入的场景。多个空背景近景若同时占据主要画格，先检查是否挤掉了环境叙事；用户强调场景时优先为这些画格补充可信空间或重新取景，而不只贴上一层背景。
- 全家福与亲子照继续使用四张横版候选，并在每格保留同一组指定成员。成员完整和自然关系优先于制造剧情；儿童动作须符合年龄和安全要求。
- 婚纱照继续按 `wedding-photo.md` 的当前预览规则执行；镜头职责要帮助九格区分，不擅自改动现有的视线和礼服要求。
- 用户选定方向并要求正式单张时，以选定画面的核心人物、关系、服装、场景和情绪为边界，重新设计适合最终用途的一张照片；不要把预览小图机械放大，也不要无故换成另一套方案。

输出前只需内部核对：用户指定的关键条件是否进入画面；人物在做什么是否清楚；镜头和光线是否服务照片用途；是否出现身份漂移、无关道具或彼此冲突的视觉细节。对用户展示实际图片和必要说明，不默认展示内部导演卡。
