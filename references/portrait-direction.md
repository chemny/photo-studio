# 创意人像摄影导演规则

适用于婚纱照、全家福、亲子照、个人形象照和艺术写真的候选画面与正式成片。证件照以官方规格、构图和身份保真为先，不套用创意导演规则。各产品的专用规范仍决定人物、服装、画幅、格数和审美边界。

## 先设计画面，再写生成要求

每张照片或每个候选画格在内部确定以下内容，不把这张检查卡当成表单展示给用户：

1. **用途与不变量**：这张照片要让人看到什么？锁定用户明确指定的入镜人物、场景、服装、色彩、动作、比例，以及已确认的身份特征。默认预设只能补空白，不能覆盖明确要求。
2. **拍摄瞬间**：选择一个可拍摄的时间切片，以及一个轻微事件或明确的稳定姿态目的。正式主合影可以是安稳看镜头，不必强加剧情；互动照应能说清人物正在共同做什么。
3. **动作链与视线**：交代身体重心、站坐关系、手部动作、人物接触点、头部方向和视线落点。多人画面还需说明谁在前、谁在后，以及是否存在自然的高低差。每个动作都要适合人物年龄、服装和场地。
4. **空间与摄影**：只选两三个能辨认环境的线索，确定景别、机位、前后层次、构图目的和光源方向。人物、衣物、道具和背景应处在同一可信光线中。
5. **一致性检查**：人物行为、服装、天气或时间、空间和光线必须能同时出现在这一瞬间。提示词要描述完整画面，不能只并列“高级、自然、电影感、漂亮背景”等词。

用户讨论穿搭方向时，先按用途、活动和其描述的正式程度选择服装版型、材质、色彩与露肤程度，再比较不同方案。若目标是“日常但精致”，用合身剪裁、真实面料和协调配色建立质感；不要自动滑向职业套装或派对礼服，也不要把某次测试的九套衣服固化成默认模板。服装变化应足以让用户看出款式差别，且与场景和人物气质一致。

根据人物和用途选择当下、得体的造型；颜色可以有亮点，但要与肤色、空间和相邻画格协调。展示身材时优先用合身剪裁、自然腰线、裙长或裤型、姿态和机位建立修长感，保持真实骨骼比例。用户指定裙装、裤装、长短款比例时按其要求编排；未指定时让轮廓与场景都有差异，避免一组服装都像制服或同一条裙子换颜色。休闲活动用适合活动的服装，正式场景也不等于每格都穿套装。

先确认每格的入镜主体名单。个人肖像默认只出现指定主体；环境可以通过建筑、物件和光线表达，不主动增添路人或观众。需要表现社交互动且用户允许他人入镜时，才安排背景人物，并检查其不抢主体、不重复面孔。用户要求移除无关人物时，保留主角、动作、空间和光线。

## 多格预览与单张成片

- 多格预览先按产品规范确定格数和比例，再为每格安排不同的拍摄目的或人物关系；场景、动作、景别和情绪应形成可见差异。更换背景或服装本身不算新的摄影瞬间。
- 多格预览以一张完整多格图为生成单位；一次图片生成呈现全部候选，并逐格检查比例、身份、人物尺度与留白。确认前不先生成多张独立图片再拼版。若用户后续要求某格的正式单张，以该格为画面方向、以原人物参考为身份依据重新生成，不把缩略画格放大成片。
- 用户仅在比较服装或风格时，直接生成一张包含所有候选的方向图；需要调整时编辑该预览，不在确认前批量制作独立画格。用户确认并要求正式单张时，才按实际用途生成所选方向并验收。
- 宽泛的人像多格预览还要安排不同的人物尺度与空间关系：头像近景用于识别人物，环境半身与全身照用于呈现可进入的场景。多个空背景近景若同时占据主要画格，先检查是否挤掉了环境叙事；用户强调场景时优先为这些画格补充可信空间或重新取景，而不只贴上一层背景。
- 全家福与亲子照继续使用四张横版候选，并在每格保留同一组指定成员。成员完整和自然关系优先于制造剧情；儿童动作须符合年龄和安全要求。
- 婚纱照继续按 `wedding-photo.md` 的当前预览规则执行；镜头职责要帮助九格区分，不擅自改动现有的视线和礼服要求。
- 用户选定方向并要求正式单张时，在内部记录选中画格与人物身份参考的不同作用：人物参考决定长相和年龄呈现，选中画格决定人物关系、服装轮廓、动作、场景线索、光线与情绪。确定交付用途和画幅后，重新生成一张完整分辨率照片；允许为画幅自然调整镜头距离与留白，不得把预览小图机械放大，也不得无故换成另一套方案。预览格里看不清的面容、手部或服装细节，不从小图猜测；优先依据清晰人物参考和可信的摄影结构补足。
- 当用户只改穿搭时，人物原参考锁定身份，已确认画格锁定场景、动作、机位和表情，穿搭方向图只提供服装信息。逐格检查三个来源是否各司其职，不能因为新衣服顺手重画原有场景或姿势。

输出前只需内部核对：用户指定的关键条件是否进入画面；人物在做什么是否清楚；镜头和光线是否服务照片用途；是否出现身份漂移、无关道具或彼此冲突的视觉细节。对用户展示实际图片和必要说明，不默认展示内部导演卡。
