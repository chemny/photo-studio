# 小规模流程回归用例

这些用例用于检查 Skill 的对话分流，不代表照片机构的官方验收。每次修改路由规则后，逐条模拟下一步回复；只有真实生成图片并检查结果，才能称为图像端到端验收。检查生成方式时须核对图片工具调用记录与实际输出数量；只看最终交付文件数不能判断是否提前批量生成。

| 输入情境 | 预期下一步 | 不应发生 |
| --- | --- | --- |
| 上传人像，说“做一张普通二寸蓝底证件照” | 按尺寸表直接制作一张正式文件，检查像素和构图 | 九宫格、开工确认、自动打开文件夹 |
| 上传人像，只说“蓝底证件照” | 集中问一次缺失的用途/尺寸/官方限制，并给普通二寸推荐 | 把“蓝底”误当作尺寸已知，或分多轮问颜色和尺寸 |
| 上传人像，只说“做一张证件照” | 集中问尺寸、底色及必要的官方限制，并给完整推荐 | 默认做九宫格来猜尺寸 |
| 上传人像，说“做港澳通行证纸质照，33×48 mm” | 按纸质规格生成，300 DPI 换算为 390×567 px，并提醒以接收机构当前要求为准 | 把纸质规格宣称为所有线上上传通道的标准 |
| 上传人像，说“做出入境证件全程网办上传照” | 按该办理入口当前官方要求核对比例、像素、格式、编辑和采集限制，并记录来源 | 直接套用390 px宽纸质照文件，或未经复核沿用旧网办固定参数 |
| 说“比较蓝底和白底效果” | 一张对比预览，标清不可提交；选定后再确认正式单张 | 把预览缩略格当成精确尺寸的交付文件 |
| 上传两人参考，说“拍婚纱照” | 一张每格 2:3 的九宫格概念图；人物、礼服、视线和动作逐格检查，每格有不同的镜头职责和可见情绪 | 九张单图、普通商务装、纯背影、大量不看镜头，或九格只是换背景 |
| 上传单人参考，说“拍婚纱照” | 单人婚礼九宫格，不凭空增添现实伴侣 | 追问是否要增添伴侣 |
| 保留原新娘参考，说“把新郎换成虚构的年轻成年男性，再做九宫格” | 先建立虚构新郎的独立参考，再用原新娘与新新郎分别锁定九格身份 | 沿用旧新郎的脸或眼镜、改变新娘面容、把虚构新郎称为真实伴侣 |
| 上传清晰三人合影，说“做全家福” | 绑定合影中的三人，先出一张含六个横版 3:2 画格的六宫格（3列×2行） | 逐个索要单人照、增加第四人或把三人拍成新人、仍出九宫格 |
| 上传六人合影，说“做三代同堂全家福” | 六人身份稳定，先出一张横版六宫格；六格都完整保留六人，场景和主要动作有明显区别 | 为套竖版压窄人物、让老人或孩子在部分画格中消失、各格只换背景 |
| 上传自己与孩子的合影，说“做亲子照” | 使用现有监护关系与两人参考，先出一张含四个横版 3:2 画格的四宫格；四格比较正式合影、居家共同活动、户外同行及另一环境的互动 | 再开独立授权确认轮次、把孩子成人化、重复抱娃动作或只换背景、仍出九宫格 |
| 只上传一个成年人，说“加上我真实的孩子做亲子照” | 合并询问孩子参考图及必要的监护授权，再继续 | 根据成年人的脸凭空捏造真实孩子 |
| 上传人像，说“做个人形象照，展示工作和生活” | 场景覆盖九宫格，正中央主形象近景；生活活动按人物目标选择 | 只做职业场景、重复歪头、所有人物都套相同的运动聚会旅行格 |
| 上传人像，说“形象照，突出个人气质和辨识度” | 特质表达九宫格，保留个人品牌用途，不强塞运动聚餐旅行 | 与场景覆盖只换背景、改脸或改体型 |
| 用户说“先把不同穿搭放在一张图里，让我快速选方向” | 直接生成一张完整方向图比较款式；需要调整时编辑预览，确认并要求单张后才制作所选方向 | 确认前先批量生成多张独立图，或未检查比例与身份就交付预览 |
| 用户认可了场景和姿势，只说“换成更现代、修长的穿搭，裙装多一些” | 保持人物身份、场景、动作和机位；调整服装轮廓、色彩及场景适配，保持真实身形 | 把人物换脸、改场景和姿势、反复使用同一款裙子，或靠拉腿显高 |
| 用户说“个人形象照里有无关路人，把他们去掉” | 仅移除无关人物，保留主角、空间透视、光线和已确认动作 | 保留路人、抹掉场景线索，或重做主角造型 |
| 上传人像，说“拍一组艺术写真” | 一张 2:3 九宫格，比较九种画面语言且不重复动作 | 用职业形象照九格换滤镜、四格托下巴 |
| 看完写真九宫格，说“几个空背景大头像太像了，想看有场景的半身或全身照” | 定向重做指定画格，拉开镜头并安排可信空间；其他画格保持原样 | 只给头像贴背景、保留重复的人物尺度，或连带重绘已认可的画格 |
| 上传人像，说“跳过预览，在窗边直接拍一张安静的艺术写真，正在翻书” | 按给定场景和动作设计单张摄影瞬间，交代视线、机位与窗光并保留人物身份 | 换成咖啡馆、只堆“电影感”等形容词，或无故生成九格 |
| 上传现有照片，说“只把背景换成明亮影棚” | 直接编辑一张图，保留人物、服装、姿势和构图，检查影棚光线与人物融合 | 默认九宫格、换脸、顺手换衣服或重摆姿势 |
| 上传现有照片，说“自然修一下肤质” | 直接轻度精修并保留年龄、原有皮肤纹理、表情和背景 | 磨成塑料皮肤、瘦脸、改变场景或多轮询问修图清单 |
| 用户说“这张九宫格可以，先保留” | 停在预览，询问是否需要单张正式成片 | 自动生成九张或一张单图 |
| 用户说“这四格家庭照先保留” | 停在四宫格预览阶段，询问是否需要所选方向的单张正式成片 | 自动追加单张正式成片或强制进入影楼目录 |
| 用户明确说“跳过预览，直接出一张” | 按产品和已知规格制作正式单张 | 强制先出九宫格 |
| 用户选中婚纱或写真概念图的一格，并明确说“把这一格做成正式单张” | 用原人物参考锁定身份，以该格锁定关系、服装、动作、场景和情绪；按用途生成并对照三者验收 | 放大预览小图、把小图当身份来源、换成另一套画面或重复询问是否开始 |
| 用户说“九宫格每格按正常比例，人物别太满” | 同一次生成提示明确 3×3 等宽高分格、每格 2:3、自然身形和留白；直接生成一张后逐格视觉检查 | 先生成九张再拼、宽高不一的分格、横向压人或只缩小头部 |

| 上传宠物，说“做一组自然写真” | 一次直接生成一张完整九宫格，保持自然体态，变化场景、景别和姿态；按用户要求不加服饰 | 先生成九张再拼、在明确自然主题中强加服饰、动作不变只换背景 |
| 上传宠物，说“直接做一张蓝底趣味证件照” | 直接制作动物头胸像，保留耳形、眼睛与花纹，明确为趣味头像产品 | 套人类头部坐标、裁耳、宣称通用官方有效 |
| 上传宠物和主人参考，说“直接做一张主人抱猫合影” | 同时保留两份身份参考，抱持有支撑，检查手爪接触 | 只锁定猫却改变主人，添加其他人或宠物 |
| 上传两只宠物参考，说“拍合影” | 分别绑定毛色与花纹，保持指定数量 | 花纹互换、复制宠物或合并身体 |
| 用户只说“把猫的背景换成影棚” | 保留品种、毛色、姿态、耳形和已确认画框，只修改背景 | 顺便换品种、加衣服或重塑毛色 |
| 证件照要求明确像素及100 KiB上限 | 保持像素，以允许的质量范围导出并检查实际字节数，不能满足则停止 | 悄悄缩小像素、输出超限文件、以压缩通过冒充视觉合格 |
| 证件照源图面部过小或头顶缺失 | 指出具体问题并请求合格源图；合成素材测试另记 | 补画五官后宣称严格保真、把文件参数通过当官方审核通过 |
| 证件照导出后头部偏小或背景残留 | 重新按最终画幅视觉检查，调整完整裁切或定向修正背景后再导出 | 只检查像素、把上方角落抽样通过当全背景纯净 |
| 全身照脸部很小且歪头，要求重做证件照 | 制作前判定源图不适用；诊断预览标注未通过，需新的合格正面素材 | 生成新脸纠正姿态后宣称原图保真、放大补画细节 |
| 文件像素合格但没有视觉记录，或姿态观察为失败 | `--require-review` 返回失败且 `delivery_ready` 为假，保留文件检查独立结果 | 将尺寸合格等同于交付合格 |
| 成片或参考更换后复用旧视觉记录 | 哈希不匹配时阻止交付；重新打开两文件并检查 | 只刷新哈希而不再看图 |
| 已确认的合成测试素材不适合证件照 | 说明源图问题，新生成的正面近照标为新测试源并先确认 | 把新造头像称为旧参考的原像素修复或真实客户保真通过 |
| 女图戴耳环、披发遮耳、浅色上衣，要求居民身份证样张 | 查接收地规则，检查首饰、眉耳及着装；真实办理按规定重拍，虚构造型测试标AI样张 | 只因尺寸、保真通过就判官方合格 |
| 只说一寸白底，未说明证件用途 | 可以做明确标记的普通尺寸样张；需官方交付则集中补用途和渠道 | 自动称居民身份证合格 |
| 中国护照纸质照，来源禁止合成或修改 | 核对33×48及头部毫米范围、采集和编辑限制，真实办理不生成换脸换装；测试仅样张 | 把AI无饰露耳样张判为可办证 |
| 考试照未给考试名称、场次、地区 | 一次问齐并查当届公告 | 沿用另一个考试旧FAQ的眼镜或字节限制 |
| 旧版视觉记录只有七项全通过 | 新检查器要求用途、来源和造型等专项记录，旧记录不能放行 | 复用旧结果或仅更新哈希 |

| 上传宠物，只说“做一组宠物写真” | 一次生成一张完整九宫格；不同角色主题、服装轮廓、配饰、动作和布景，原动物身份与体态保持 | 默认全是裸毛生活照、只换场景、后台先生成九张再拼 |
| 主题宠物九宫格收到“这套很好，后面按这个逻辑” | 记录认可的主题造型逻辑，等待选片或制作要求 | 自动再生成九张或擅自制作某格单张 |
| 用户说“第2格确定了，把它做成单张” | 用原宠物参考锁定身份，第2格锁定主题服装、配饰、场景和动作，只制作这一张 | 把九张都生成、重复询问是否开工、只放大预览缩略格 |
| 人像、婚纱、艺术或宠物主题首次预览 | 图片工具一次生成一张完整九宫格，逐格视觉检查比例、身份与构图 | 用“最后只展示一张”解释后台九次单图生成 |
| 首次全家福／亲子照预览 | 全家福一次生成一张完整六宫格（可按需九格），亲子照四宫格；单格均横版3:2 | 为了方法统一无视产品默认或用户明确格数、先生成四张再拼 |

所有用例还应检查：上传参考始终作为身份锚点；只在对话展示结果，不自动打开文件管理器；客观图像失败最多自动返修一次。发布前至少跑通文本路由用例，并对新变动类别按其当前默认版式完成视觉测试；合成参考图测试不能替代真实人物照片的身份保真验收。

| 输入 | 预期行为 | 不应出现 |
|---|---|---|
| 用户说“全家福更值得留念，尽量一次生成” | 先锁定画幅与分镜，直接生成一张；六格覆盖正式、两居家、两户外、纪念，未知纪念事件用普通家庭纪念合影 | 编造生日／入学信息、硬凑豪华场所、为轻微留白连续生成多版 |
| 分格与体型自然，留白稍偏参考区间 | 展示供用户判断，保留实际检查局限 | 把数字区间当绝对门槛反复重做或宣称文本自检证明人物保真 |
