# 图片质量检查

质检默认在后台完成，不要求用户逐项确认。明显失败的结果不要展示；针对客观问题最多自动重试一次，避免无限生成。

## 通用检查

- 主体数量、身份和年龄呈现是否正确；
- 是否出现未请求的路人、观众或重复人物；确需背景人物时，是否符合场景且不抢主体；
- 脸、眼睛、牙齿、手指和四肢是否自然；
- 眼镜、首饰、领口、纽扣和其他配饰是否变形；
- 背景是否穿透、漂浮、融合、脏污或出现不需要的物体；
- 构图、比例、裁切、留白、曝光和白平衡是否符合目标；
- 文字是否逐字匹配用户提供的内容；
- 是否存在水印、乱码、内部编号或重复主体；
- 输出像素、格式、压缩和文件数量是否符合用户要求。

逐人逐格按 `portrait-safe-area.md` 的“多格预览的画幅与体型一致性”核对原素材与结果的脸宽高、肩头关系、躯干、四肢和相对身高；检查实际分格尺寸与行列计算。框正确但人物明显增胖或瘦身仍判失败。

## 产品专项检查

婚纱照、全家福／亲子照、个人形象照和艺术写真的单图、多格概念图，均按 `portrait-safe-area.md` 检查构图安全留白。多格图每格单独测量：普通景别发顶留白优先 4%–8%，头像近景 3%–6%，无特别意图时低于 3% 或发顶贴边应重点检查，确实拥挤、切头或违反用户明确要求时才自动返修；头部距左右边界默认至少 4%，多人需逐人检查。左右可因动作和排字需要不对称，但不能意外切断头发、脸、手脚或需要完整展示的服装。修正后还要看顶部空间是否过大、人物是否显得下沉；有明确环境或排版用途的留白不按普通肖像处理。修正时只调整取景、镜头距离或完整人物的等比尺寸，不局部缩改头部。

### 证件照

首先按 `id-photo-official-requirements.md` 核对用途、地区／接收机构、渠道和来源，逐项检查头发是否遮眉眼耳、首饰、衣服与领口、妆容眼镜、表情、用途几何、处理许可及采集方式。缺用途或规则待定时不能交付为官方合格。虚构素材或生成式造型预览只能作为AI测试样张；即便造型通过，也必须保持正式 `delivery_ready: false`。纸质照几何与网办文件参数不得混用，通用头肩参数也不替代用途标准。

先执行 `id-photo-delivery.md` 的源图停止门槛。明显歪头或脸部原始细节不足时，不进入正式成片流程。严格保真只能保留原主体像素进行非生成式处理，不能生成新头像后做文件检查冒充保真通过。导出后打开最终独立文件与原图等比例对照，记录七项视觉观察及两份文件的 SHA-256，再用 `check_id_photo.py --source … --review … --require-review`；`delivery_ready: false` 即不能作为合格成片交付。新版本必须重新视觉检查，不能只刷新哈希。合成测试人物也适用，新的正面素材须与原像素修复明确区分。

按 `id-photo-composition.md` 检查正面视线、主体水平中心、头顶留白、头部高度、下巴位置、颈部完整性和双侧肩部可见性；同时检查纯色背景、眼镜边缘、面部自然纹理以及指定像素、毫米和 DPI。按 `id-photo-delivery.md` 和 `scripts/check_id_photo.py` 检查真实编码格式、RGB、透明度与体积上限；导出后重新检查头肩。检查器不识别人脸和全背景，不把角落抽样通过当成完整视觉合格。只有裁切框平移、完整人物等比缩放或纯色背景补边可用于修正构图；不得局部移动或缩放下巴、头部和肩膀，不得过度磨皮或改变真实五官。官方用途只说明规格结果，不宣称一定通过审核。

证件照需求明确时检查是否绕过不必要的九宫格；规格缺失时检查是否集中询问一次并提供推荐方案。官方用途还要核对办理渠道，避免把纸质照片的毫米规格及 300 DPI 换算像素直接当成电子上传要求。用户明确要求底色或效果对比时，检查拼图是否被标为预览、没有被当成可提交文件；尺寸须以对照表和最终文件参数核对，不能从缩略格外观判断。

### 婚纱照

按 `wedding-photo.md` 检查每位主体的身份标签、服装槽位和人数；禁止交换五官、服装、身体或肢体。检查脸型、五官比例、年龄呈现、发际线、标志性特征、身高差和基本体型是否异常变化。重点检查手指、牵手、拥抱、搭肩等接触区域，以及婚纱、头纱、裙摆、西装、领口、首饰、光线、人物比例和背景透视。不得出现额外人物、重复面孔、多余肢体或融合身体。

若只替换其中一位新人，逐格对照未替换者的原身份参考与替换者的新参考；旧人物的面容、眼镜或其他标志不能残留在结果中。旧双人拼图不能取代这两份独立身份参考。

默认现代方案还要先检查婚纱照识别度：双方应明确呈现为新人。男主不得像普通商务人士、陪同人员、酒店服务人员或服务生；默认避免普通商务西装配普通黑领带，优先检查礼服领型、正式衬衫、领结或婚礼仪式服装是否成立。服装、灯光、空间、动作和构图必须共同支持场景；不能只换背景而保留完全相同的站姿与造型。出现传统影楼式红金堆叠、每张必有大花束、蕾丝甜心领与亮面西装组合、胸花口袋巾堆叠、暖黄褐宴会厅色偏或明显美颜滤镜时，视为不符合默认现代审美。花束不得遮挡腰线、领口和主要礼服轮廓；新中式默认避免密集刺绣、满幅红金和戏服化背景。

方向讨论用多格概念图须确认初次预览只直接生成了一张完整九宫格，没有提前生成九张独立图再拼；还要检查跨格差异：每格必须是竖版 2:3，九宫格采用 3 列 × 3 行并形成 2:3 整图，不得混用画格比例或拉伸人物。逐格确认其镜头职责、可见情绪和具体动作；相邻画格不能同时重复职责、景别与互动关系。至少五种可辨认的婚礼服轮廓，动作、场景、光线和景别必须可一眼区分；传统长拖尾最多一格；“牵手并排行走”最多一格，完全相同的动作或互动关系最多一格。镜头视线应占主导：九宫格至少六格双人看镜头、至少八格有一人看镜头，最多一格因慢舞等明确叙事需要两人都不看镜头。默认不得出现纯背影，侧身也应保留清晰可辨认的脸。逐格对比身体朝向、接触点、人物距离、前后层次和高低关系；只换背景或服装但保留同一动作，直接判定不合格。九宫格至少覆盖三格全身或近全身、一坐一站、动态旋转或慢舞、正式合影、前后景分层和近距离互动；宽泛比较时环境覆盖室内、城市、自然等类别，具体场景按用户目标选择，用户明确指定海滩时检查沙地与海面是否可信。用户选定方向后先询问是否需要单独高清成片。

### 全家福与亲子照

按 `family-portrait.md` 逐格核对每位指定成员的身份、年龄、人数与相对身高；多代成员不得全部变成同龄人，儿童不得成人化或改变身形。不得增添用户未提供的现实亲属，也不得复制同一张脸来填满画面。重点检查牵手、拥抱、抱娃、搭肩、交叠手臂和儿童脚部，禁止身体融合、额外手指或危险、不符合年龄的动作。所有成员须可见且可辨，最高者的发顶与组合两侧不能贴边。

全家福默认一张3列×2行六宫格（无分隔线整图9:4，可按需九格）；亲子照默认2列×2行四宫格（整图3:2）。单格均为横版 `3:2`；所有画格保持同一入镜名单，禁止非等比缩放。左上角主合影人数和脸部应最清楚；全家福六格按 `family-portrait.md` 覆盖正式合影、两格居家、两格户外与一格有依据的纪念场景；没有具体纪念事件时采用普通家庭纪念合影。亲子四格比较不同共同活动；不以地点数代替互动质量，且至少两格有多数成员看镜头。逐格对照背景空间、机位、景别、站坐层次、动作与接触点；除正式及纪念合影外，若活动格只换布景或服装、仍重复相同站姿／抱娃姿势，判定方向失败。孩子或老人反复消失、只见亲子一方、手臂接触异常，也判定失败。用户确认后先询问是否需要单张正式成片。

### 个人形象照

按 `personal-branding.md` 检查人物相似度、年龄呈现、职业可信度、视线、表情、手部、服装完整性、裁切、背景真实性、使用场景和输出比例。默认必须保留脸型、五官比例、肤色、发际线、眼镜、体型和标志性特征；不得通过重塑骨相、过度磨皮或模板化网红脸制造所谓高级感。

检查服装、空间和道具是否真正支持人物角色。普通西装不得呈现服务生、保安、房产中介或销售模板感；创业者不得靠无意义的笔记本电脑、咖啡杯或手机堆砌身份；讲师不得指向空白屏幕，不得出现虚构白板、书名和屏幕乱码；背景不得是明显虚假的豪华办公室或廉价办公区虚化。

逐格检查服装与活动、空间和正式程度是否匹配；颜色是否协调而有层次；同组服装是否真正变化了裙长、裤型、廓形或面料，而非仅换颜色。人物可以借助衣服剪裁、自然姿态和机位呈现修长感，脸、肩、腰、腿的真实比例不可变形。用户指定裙装或裤装比例时按其要求验收。默认只保留指定主体；发现无关人物时移除并复查主角与场景是否被改动。

个人形象照默认以看镜头为主。头像检查缩略图识别度、发顶与双肩完整性；半身和全身检查手部、关节裁切与人物自然比例；横版宣传图检查负空间是否符合用户指定的排字方向，并禁止生成占位文字。若结果更像证件照、普通写真、销售模板或虚假成功人士，而非明确的个人品牌肖像，判定为方向失败。

九宫格概念图需检查跨格差异：每格必须是竖版 2:3，3 列 × 3 行后整图也是 2:3，不得混用画格比例。至少六格看镜头，最多三格因明确叙事需要不看镜头；抱臂最多一格，相同动作最多一格；至少覆盖头像近景、半身或大半身、全身或近全身和留白布局预览。宽泛比较时同时包含职业类的正式站姿、坐姿或倚靠、环境工作、自然讲解，以及至少两种与人物相符的不同生活活动；生活场景不能只是职业装换背景。运动、聚会、旅行等被选用时要符合对应活动和环境，且保留主体脸部可辨认度。各格只能等比缩放，不得拉伸或压缩人物。用户明确限定纯职业或其他主题时，按该主题检查九格多样性，不强制生活场景。用户选定方向后先询问是否需要单张高清成片。

再逐格对照场景、服装轮廓、发型、表情、头部方向、动作和景别：宽泛九宫格至少有三种表情状态，不得多数画格同向歪头或反复使用同一套标准微笑；发型变化以原有发长和身份保持为前提，短发人物不硬凑三种发型。默认正中央应是清晰看镜头的主形象近景，发顶留白按近景目标检查，商场等环境叙事应在外围；用户明确指定其他中心内容时除外。只换背景、颜色但其余表达几乎一致，视为多样性不足。购物格若被明确指定为商场，应有可信的室内空间线索，不能以露天街道代替。服装显臃肿时检查剪裁与取景，保留真实体型，不通过局部瘦身或非等比缩放“修复”。这些检查只用于多方向对比图，不强加给单张形象照。

### 艺术写真

按 `artistic-portrait.md` 检查风格是否达到要求，同时保证熟悉主体的人仍能辨认；强风格化不能掩盖明显身份漂移。与个人形象照的职业与生活矩阵相比，应体现审美和情绪语言的差异，而不只是换滤镜。

默认概念图检查是否只生成一张九宫格、每格 2:3，且服装、动作、表情与光线有真正差异。托下巴、抱臂、扶头发等显眼手势各最多一格，不得多数格同向歪头；检查至少三种表情状态、不同服装轮廓和各景别，避免四格以上动作重复。宽泛探索时还要检查纯背景近景是否过多、人物尺度是否雷同、场景是否可辨；用户强调场景代入感时以环境半身和全身照为主。每格按 `portrait-safe-area.md` 检查留白并保持自然身形。用户确认方向后不得自动追加单张，应先询问是否需要正式成片。

### 现有照片编辑

按 `photo-editing.md` 对比原图与结果：指定变化是否完成；未指定的人物、人数、脸、姿态、服装、背景、景别和画框是否保持；换背景的受光、透视与接触阴影是否可信；换装的领口、手部遮挡和衣摆是否自然；轻度精修是否保留年龄与皮肤纹理。修改一处却破坏其他区域时，不能把新版直接交付。

### 表情包

检查表情是否清楚、文字是否准确、透明背景是否真的包含 Alpha，以及整套风格是否一致。

### 宠物写真

按 `pet-portrait.md` 对照原参考检查毛色分界、毛量、耳形、眼睛、鼻口、尾巴、爪子、解剖与合理遮挡；完整体态保护耳尖、爪和尾巴留白。默认主题九格须在主题、服装轮廓、配饰、动作与布景形成可见区别，不能只有场景变化；确认前只直接生成一张预览。服装适配真实动物身体，不遮盖身份特征；明确要自然写真时遵循自然造型。主人同框同时核对人脸及手爪接触；趣味证件照按动物构图验收。

## 选中画格转正式单张

正式单张生成后同时对照三项：原人物参考核对每位主体的面容、年龄和标志性特征；选中画格核对人数与关系、服装轮廓、主要动作、场景线索、光线和情绪；交付用途核对景别、裁切、画幅、像素与格式。画幅变化允许自然重构边缘和留白，但不能以此为由改变所选方向。再按上面的通用及产品专项规则检查脸、手、肢体、接触点和画质。明显偏离身份或选片核心要素时，按客观失败处理；重试后仍不合格则说明具体偏差，不把相似的另一套画面当作所选成片交付。

## 自动处理与返修

- 身份漂移、主体数量错误、严重肢体异常、文字错误、背景不符合或尺寸错误属于客观失败，可以自动重试一次。
- 第二次仍不合格时停止，向用户说明问题和可选处理方式。
- 合格结果直接展示，并用一句话邀请用户描述修改意见，不发逐项验收清单。
- 创意肖像候选预览确认后，若用户没有明确要求单张，先询问是否制作，不把选片、点赞或保留拼图当成制作授权。用户明确要求直接出成片时不强制预览。
- 用户提出返修后只修改指定内容，其他构图、身份、服装和风格作为不变量重复写入编辑提示。
- 多格图只返修指定画格时，检查未指定画格是否被生成工具连带重绘；若发生变化且工具允许，可从旧版无损保留这些画格，仅把合格的新画格放回原拼图。不能把其他画格被改动的整图直接视为定向返修成功。
- 返修前保留旧版。返修后并排比较新旧版：用户指定的问题是否改善，身份是否仍符合其确认的参考图，未指定区域、构图和画质是否保持。多格图还要逐格检查未指定画格。
- 若新版修好一处却明显破坏身份或其他画格，视为返修失败，不因版本更新而直接交付新版。旧版仍可用时保留较好的旧版并说明未解决的问题；新旧版都不合格时停止并说明具体缺陷，不循环生成。
- 内部文件名可保留版本关系，但不向用户展示技术编号。

## 默认一次生成与返修边界

- 生成前一次确定参考图角色、人数、单格比例、行列和整体画布，再列每格一个主要活动。提前消除提示冲突，不在出图后临时改变画幅。原始身份和体型、人数、自然肢体、画幅优先；服装、光线及场景为其服务。
- 直接生成一张完整预览，默认只调用一次；不要为了多做比较而预先生成多个版本或独立画格。提示词用“完整入镜、头脚有余量、自然机位”等明确取景语言，避免逐格堆叠大量百分比、相互牵制的姿势或非必要服装细节。数值区间用于内部参考检查，不逐项机械转写为生成指令。
