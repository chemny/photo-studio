# 证件照尺寸映射

用于将用户的日常叫法一对一映射到可执行的电子照片规格。这是工坊的内部通行口径，不宣称所有机构对同一名称都采用相同定义。机器可读数据以 `../assets/id-photo-sizes.json` 为准。

## 通行尺寸表

像素按 300 DPI 从毫米换算并取整。

| 标准名称 | 可识别叫法 | 宽×高（mm） | 宽×高（px） |
|---|---|---:|---:|
| 小一寸 | 小1寸、小一吋 | 22×32 | 260×378 |
| 普通一寸 | 一寸、1寸、标准一寸 | 25×35 | 295×413 |
| 大一寸 | 大1寸、大一吋 | 33×48 | 390×567 |
| 小二寸 | 小2寸、小两寸、小二吋 | 35×45 | 413×531 |
| 普通二寸 | 二寸、两寸、2寸、标准二寸 | 35×49 | 413×579 |
| 大二寸 | 大2寸、大两寸、大二吋 | 35×53 | 413×626 |

另设出入境证件**纸质照**参考规格 33×48 mm、390×567 px。它与大一寸尺寸相同，但用途、背景和头部合规要求需要独立处理。此规格不能直接当作所有线上上传通道的像素要求。

## 解析优先级

1. 用户明确给出的像素或毫米，以及已知办理渠道的官方限制；两者冲突时先指出冲突，不把不合规文件称为可提交成片；
2. 用户明确给出的证件、国家、地区、提交渠道、考试或报名用途及其官方要求；
3. 本文档的尺寸名称和别名；
4. 完全缺少规格时，使用普通二寸 413×579 px。

例如：

- “小二寸照片”直接解析为 35×45 mm、413×531 px。
- “港澳通行证纸质照 33×48 mm”按明确的纸质规格解析为 390×567 px（300 DPI 换算）。
- “出入境证件全程网办上传”不能套用 390×567 px；按当前办理渠道的官方像素、比例、格式及文件限制输出。
- “小二寸，413×531”按用户明确像素输出。
- “二寸，354×472”按用户明确像素输出，不强制改成预设。

“小二寸”在现实中存在 35×45 mm 和 33×48 mm 两种口径。为避免反复追问，裸名称固定使用 35×45 mm。只说“中国护照、中国签证、出入境证件、港澳通行证”而未说明提交渠道时，不自动把纸质 33×48 mm 的 390×567 px 当成电子上传规格；合并询问一次办理渠道或接收机构的要求，并提供纸质照与线上上传的分流建议。官方要求优先于通行尺寸名称。

出入境网办的像素、比例与体积要求按实际入口当前规则核对；不固化未经当前渠道核实的网办参数。390 px 宽只是33×48 mm纸质照按300 DPI换算的结果，不能据此判断电子上传是否合规，也不能据此承诺审核通过。

## 构图与导出

- 官方用途先查 `id-photo-official-requirements.md`。居民身份证26×32 mm参考不等于普通一寸／二寸，也不能用300 DPI换算自行推断当地电子采集尺寸；护照纸质照与网办上传分别核验。未核实渠道时尺寸样张不具备官方用途合格结论。
- 通用构图范围、标记点定义和调整顺序见 `id-photo-composition.md`，机器可读参数见 `../assets/id-photo-composition.json`。
- 尺寸预设只决定最终画幅和导出像素；背景色是独立字段，不要由“一寸”或“二寸”自动推断。
- 不同规格的宽高比不同，应按目标画幅裁剪或补充纯色背景，不得拉伸人物。
- 允许整个人物图层统一等比缩放和平移；禁止单独改变头部大小、非等比变形或重绘面部、头发、肩膀和服装。
- 源图缺失头顶、下巴或必要肩部时，不用生成式补全冒充原图；请用户更换照片。
